# rust-disk-usage-analyzer

Сверхбыстрый консольный анализатор занятого места на диске на языке Rust.

## Возможности
- Рекурсивный обход директорий с подсчетом размеров файлов и папок.
- Наглядная визуализация занимаемого пространства (ASCII прогресс-бары).
- Автоматическое форматирование в человекочитаемые единицы (B, KB, MB, GB).
- Сортировка по размеру для выявления самых "тяжелых" каталогов.
- Фильтрация по порогу размера и ограничение глубины вывода.

## Сборка
```bash
rustc -O src/main.rs -o releases/rust-disk-usage-analyzer.exe
```

## Использование
```bash
# Анализ текущей папки
./releases/rust-disk-usage-analyzer.exe

# Анализ конкретной директории
./releases/rust-disk-usage-analyzer.exe C:\Users\fonya\Downloads
```
